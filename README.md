## What it does

`main.ts` (Node 22, TypeScript, no dependencies) writes one complete story in
exactly six words to `/output/entry.txt`:

> Sold the house. Kept the key.

A whole life in six words: a home sold, an era ended — yet the key is
kept. Why keep a key to a house you no longer own? The reader fills that in.

## Run it

```sh
node main.ts
# or, outside the grader:
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

The output is a fixed string in code — no network, no randomness, no clock —
so every run writes the same bytes.
